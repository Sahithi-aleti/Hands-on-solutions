# LibraryManagementEx4

This Maven project demonstrates a Spring-based application setup with the following:
- Spring Context, Spring AOP, and Spring WebMVC dependencies
- Maven Compiler Plugin configured for Java 1.8

## Project Structure
- `pom.xml`: Contains dependencies and plugin configuration

## How to Build
Run the following command in this directory:

```
mvn clean install
```

## How to Run
This module is for demonstrating Maven and dependency setup. Add your Java source files under `src/main/java` as needed.
